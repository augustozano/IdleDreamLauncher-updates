# IdleDream Launcher

Instalador Windows e canal público de atualizações do IdleDream Launcher.
O código do aplicativo permanece no repositório privado do projeto.

[Baixar o instalador mais recente](https://github.com/augustozano/IdleDreamLauncher-updates/releases/latest)

Quem usa uma versão antiga precisa instalar a versão 1.0 uma vez, fechando o launcher antes de instalar.
Contas e configurações são preservadas. Depois, o botão do launcher fica amarelo quando há atualização:
ao clicar, baixa, instala e reabre automaticamente.

Este repositório distribui somente instaladores e informações de atualização assinadas.
Não é necessário ter conta no GitHub para baixar ou atualizar.
